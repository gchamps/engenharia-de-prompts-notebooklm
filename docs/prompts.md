# Engenharia de Prompts

Neste documento serão registrados todos os prompts utilizados durante o estudo.

## Prompt 1

**Pergunta:**
Faça um resumo geral de todas as fontes, destacando os principais assuntos abordados e indicando quais conceitos aparecem em mais de um documento.

**Objetivo:**
Obter uma visão geral do conteúdo.

**Resultado:**
A IA apresentou um panorama dos conceitos principais, destacando os temas recorrentes.

**Aprendizado:**
Esse prompt foi útil para iniciar o estudo e identificar os tópicos mais importantes.
