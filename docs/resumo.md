# Resumo – Engenharia de Prompt para IA Generativa

## Introdução

A Engenharia de Prompt é a prática de criar, estruturar e aperfeiçoar instruções para interagir de forma eficiente com modelos de Inteligência Artificial Generativa, como ChatGPT, Gemini e Claude. Seu objetivo é orientar o modelo para produzir respostas mais precisas, relevantes e adequadas ao contexto da tarefa.

Durante este estudo, foram utilizadas fontes oficiais para compreender os princípios da Engenharia de Prompt, explorar diferentes técnicas de prompting e analisar boas práticas para obter melhores resultados com modelos de linguagem (LLMs).

---

## O que é Engenharia de Prompt?

A Engenharia de Prompt consiste no processo de elaborar instruções claras e objetivas para direcionar o comportamento de um modelo de IA. Um prompt bem estruturado reduz ambiguidades, melhora a qualidade das respostas e aumenta a eficiência na resolução de problemas.

Essa habilidade tornou-se essencial para profissionais que utilizam IA em atividades como desenvolvimento de software, análise de dados, criação de conteúdo, atendimento ao cliente, educação e automação de processos.

---

## Como funcionam os Modelos de Linguagem (LLMs)

Os Large Language Models (LLMs) são modelos treinados com grandes quantidades de dados textuais para compreender padrões da linguagem natural e gerar respostas coerentes.

Esses modelos não "pensam" como seres humanos. Eles identificam padrões estatísticos nos dados de treinamento para prever a sequência mais provável de palavras com base no contexto fornecido pelo usuário.

A qualidade da resposta depende diretamente da clareza das instruções, do contexto disponível e das limitações do próprio modelo.

---

## Principais Técnicas de Prompting

Durante o estudo foram identificadas diversas estratégias para melhorar a interação com modelos de IA:

* **Zero-shot Prompting:** o modelo recebe apenas a tarefa, sem exemplos prévios.
* **One-shot Prompting:** um único exemplo é fornecido para orientar a resposta.
* **Few-shot Prompting:** vários exemplos são utilizados para demonstrar o formato esperado.
* **Role Prompting:** define um papel para a IA, como "atue como um professor" ou "atue como um analista de dados".
* **Chain of Thought:** incentiva o modelo a explicar seu raciocínio passo a passo antes de apresentar a resposta final.

Cada técnica possui aplicações específicas e pode ser combinada de acordo com o objetivo da tarefa.

---

## Boas Práticas

As fontes analisadas destacam que um bom prompt deve:

* Definir claramente o objetivo da tarefa.
* Fornecer contexto suficiente para orientar o modelo.
* Especificar o formato esperado da resposta.
* Informar restrições quando necessário.
* Solicitar exemplos ou justificativas quando apropriado.
* Refinar o prompt de forma iterativa até obter o resultado desejado.

Essas práticas aumentam a precisão das respostas e reduzem interpretações equivocadas.

---

## Desafios Encontrados

Durante os testes realizados no NotebookLM, foi possível observar alguns desafios comuns:

* Respostas muito genéricas quando o prompt era pouco específico.
* Informações excessivamente longas sem um formato definido.
* Necessidade de adicionar contexto para obter respostas mais relevantes.
* Importância de solicitar exemplos práticos para facilitar a compreensão.
* Necessidade de limitar as respostas às fontes utilizadas durante o estudo.

Esses desafios demonstraram que a qualidade da resposta depende diretamente da qualidade do prompt.

## Principais Aprendizados

Ao longo deste projeto foi possível compreender que:

* A Engenharia de Prompt é uma competência essencial para o uso eficiente de modelos de IA.
* Pequenas alterações na estrutura de um prompt podem gerar respostas significativamente melhores.
* Fornecer contexto, definir objetivos claros e especificar o formato esperado são fatores fundamentais para obter bons resultados.
* O refinamento contínuo dos prompts faz parte do processo de aprendizagem e melhoria das interações com a IA.
* O NotebookLM é uma ferramenta eficiente para organizar conhecimento, sintetizar informações e apoiar estudos baseados em múltiplas fontes.
