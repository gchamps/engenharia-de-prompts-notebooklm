# 📚 Engenharia de Prompt para IA Generativa com NotebookLM

> Projeto desenvolvido como parte do desafio da **DIO (Digital Innovation One)** com o objetivo de explorar o uso do **NotebookLM** como ferramenta de aprendizagem ativa, utilizando técnicas de Engenharia de Prompt para organizar conhecimento, sintetizar informações e criar um miniguia de estudos.

---

## 📖 Sobre o Projeto

A Engenharia de Prompt tornou-se uma competência essencial para profissionais que utilizam Inteligência Artificial Generativa. Este projeto demonstra como utilizar o NotebookLM para estudar um tema de forma estruturada, explorando diferentes estratégias de prompting, documentando o processo de aprendizagem e consolidando o conhecimento em um guia reutilizável.

Durante o desenvolvimento, foram utilizadas fontes oficiais, testes de diferentes tipos de prompts e refinamentos sucessivos para compreender as melhores práticas de interação com modelos de linguagem (LLMs).

---

# 🎯 Objetivos

* Estudar os fundamentos da Engenharia de Prompt.
* Utilizar o NotebookLM como ferramenta de aprendizagem.
* Realizar curadoria de fontes confiáveis.
* Experimentar diferentes estratégias de prompting.
* Documentar dificuldades, melhorias e aprendizados.
* Criar um miniguia de estudos reutilizável.
* Desenvolver um projeto para compor meu portfólio no GitHub.

# 🧠 Metodologia

O estudo foi realizado seguindo as etapas abaixo:

1. Definição do tema.

# 💡 Principais Aprendizados

Durante o desenvolvimento deste projeto foi possível compreender que:

* A qualidade das respostas depende diretamente da qualidade dos prompts.
* Contexto, clareza e especificidade são fundamentais para obter melhores resultados.
* O refinamento iterativo dos prompts melhora significativamente as respostas geradas pela IA.
* O NotebookLM é uma excelente ferramenta para organizar estudos baseados em múltiplas fontes.
